Подключение AI-ассистента (MCP)

Токен позволяет AI-ассистенту (например, Claude) читать аналитику продаж только вашего аккаунта. Адрес сервера: …, авторизация: заголовок Authorization: Bearer <токен>.

Скопируйте этот ключ сейчас — он больше не будет показан повторно.

Как подключить MCP-сервер в популярных AI-инструментах

Для подключения в любом инструменте, поддерживающем MCP, понадобятся два значения:

  • Адрес сервера (URL): …
  • Заголовок авторизации: Authorization: Bearer <ваш токен> (токен создаётся кнопкой выше)
Claude Desktop / Claude Code

Интерфейс Claude Desktop пока не позволяет указать произвольный заголовок авторизации напрямую, поэтому подключение прописывается в конфигурационном файле через вспомогательный пакет mcp-remote (требуется установленный Node.js):

  1. В Claude Desktop откройте Settings → Developer → Edit Config (откроется файл claude_desktop_config.json).
  2. Добавьте в секцию mcpServers блок ниже — сначала создайте токен кнопкой выше, тогда он подставится в пример автоматически.
  3. Сохраните файл и перезапустите Claude Desktop.

                                                                    
                                                                

                                                            

                                                        


                                                        

                                                            Claude.ai (веб), ChatGPT и другие сервисы с поддержкой MCP-коннекторов
                                                            

                                                                

                                                                    Эти сервисы поддерживают вход через OAuth — токен создавать не нужно, ProfitBot сам
                                                                    предложит войти и подтвердить доступ. Например,
                                                                    в Claude.ai: Settings → Connectors → Add custom connector; в ChatGPT: раздел Connectors / Apps
                                                                    (доступность и точные названия пунктов меню могут отличаться и меняться со временем — уточняйте
                                                                    в актуальной документации сервиса). В форме подключения достаточно указать только:
                                                                

                                                                
    
                                                                    
  • Адрес сервера (URL) — см. выше
    • 
                                                                

                                                                

                                                                    После добавления сервис откроет окно входа в ProfitBot (если вы ещё не авторизованы) и
                                                                    экран подтверждения доступа — после подтверждения сервис получит собственный токен,
                                                                    который отобразится в таблице выше и который можно отозвать в любой момент.
                                                                    Если нужный сервис поддерживает только заголовок авторизации без OAuth — используйте
                                                                    статический токен, как описано выше.
