# Дизайн-токены: полный список

Имена обязательны для кабинета, лендинга и **каждой** темы витрины. Значения
ниже — стартовые для кабинета и базовой темы. Темы и продавцы меняют значения, а
не имена. Контраст пересчитывай тестом после любого изменения, цифры в таблице
ориентировочные.

## Цвета

| Токен | Светлая | Тёмная | Назначение |
|---|---|---|---|
| `--color-bg` | `#f6f7f9` | `#0f1115` | фон страницы |
| `--color-surface` | `#ffffff` | `#171a20` | карточки, шапка, модалки |
| `--color-surface-2` | `#f0f2f5` | `#1f232b` | вложенные блоки, заголовки таблиц, hover строк |
| `--color-text` | `#1b1f24` | `#e6e8eb` | основной текст |
| `--color-text-muted` | `#5c6673` | `#9aa4b2` | подписи, второстепенный текст |
| `--color-border` | `#e2e5ea` | `#2c313a` | границы, разделители |
| `--color-border-strong` | `#848e9c` | `#646c78` | границы полей ввода |
| `--color-primary` | `#2563d9` | `#7aa5ff` | кнопки, ссылки, акцент |
| `--color-primary-hover` | `#1d4bb0` | `#9dbcff` | hover/active |
| `--color-on-primary` | `#ffffff` | `#0f1115` | текст на `primary` |
| `--color-success` / `-bg` | `#1d7a45` / `#e6f5ec` | `#5fd08e` / `#12291c` | статусы «оплачен», «активен» |
| `--color-warning` / `-bg` | `#8a5a00` / `#fff4d6` | `#f2c14e` / `#2e2410` | предупреждения |
| `--color-danger` / `-bg` | `#b02a2a` / `#fdeaea` | `#ff8a8a` / `#331616` | ошибки, удаление |
| `--color-info` / `-bg` | `#1f5fbf` / `#e8f0fd` | `#8ab4ff` / `#14213a` | подсказки |
| `--color-media-bg` | `#ffffff` | `#f2f3f5` | подложка фото товаров и логотипов |
| `--color-focus` | `#2563d9` | `#9dbcff` | кольцо фокуса (`outline` 2px + offset 2px) |
| `--color-overlay` | `rgb(16 24 40 / .45)` | `rgb(0 0 0 / .6)` | фон под модалкой |
| `--chart-1…6` | 6 цветов | 6 светлее/менее насыщенных | графики кабинета |

## Прочее

| Токен | Значение | Примечание |
|---|---|---|
| `--shadow-1`, `--shadow-2` | мягкие тени | в тёмной теме `none` или едва заметная тень + светлее `surface` |
| `--radius-s/m/l` | 6 / 10 / 16 px | |
| `--font-body` | системный стек или шрифт темы | подмножество с казахскими буквами (ә, ғ, қ, ң, ө, ұ, ү, һ, і) |
| `--space-1…8` | 4…48 px | шаг 4 px |

## Пары для теста контраста (оба режима)

| Текст / элемент | Фон | Минимум |
|---|---|---|
| `text` | `bg`, `surface`, `surface-2` | 4.5 |
| `text-muted` | `bg`, `surface`, `surface-2` | 4.5 |
| `on-primary` | `primary`, `primary-hover` | 4.5 |
| `primary` (ссылки) | `bg`, `surface` | 4.5 |
| `success`, `warning`, `danger`, `info` | свой `-bg` и `surface` | 4.5 |
| `border-strong` | `surface` | 3 |
| `focus` | `bg`, `surface` | 3 |
